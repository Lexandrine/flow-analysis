# Реестр требований: связываем обещание и доказательство

| ID / требование | Источник / приоритет | Проверка | Статус |
|---|---|---|---|
| **F-01:** автоматически выгружать сырые 5-минутные данные (скорость, интервалы, класс ТС) по ID объекта и заданному периоду времени | Заказчик / обязательно | Запрос к БД «ВостокМ»; сверка объёма и полноты выгрузки с эталоном | Реализовано, проверено |
| **F-02:** обогащать данные контекстными признаками (время суток, день недели, доля грузового транспорта, погодные условия) | Аналитик / обязательно | Unit-тесты на тестовой выборке; проверка наличия всех признаков в итоговом датасете | Реализовано, проверено |
| **F-03:** выполнять ML-скоринг каждой аномалии — присваивать вероятность ложного срабатывания (0–100%) | Аналитик / обязательно | Сравнение прогнозов модели с экспертной разметкой на выборке из 100+ аномалий; расчёт F1-score | Реализовано, в тестировании |
| **F-04:** применять контекстную фильтрацию — автоматически отсеивать аномалии, объяснимые суточными/недельными паттернами или погодой | Заказчик / обязательно | A/B-тест: доля ложных срабатываний до и после применения фильтра на исторических данных за 3 месяца | Реализовано, не проверено |
| **F-05:** предоставлять интерфейс экспертной разметки — инженер одним кликом помечает аномалию как «истинную» или «ложную» с указанием причины | Пользователь / обязательно | Юзабилити-тест с 2–3 инженерами; замер времени разметки одной аномалии | Не реализовано |
| **F-06:** генерировать итоговый отчёт (CSV/PDF) со списком объектов, где алгоритм компании систематически ошибается, и рекомендациями по корректировке порогов | Заказчик / обязательно | Ручная проверка отчёта на соответствие шаблону; валидация рекомендаций экспертом | Не реализовано |
| **F-07:** обеспечивать адаптивную калибровку — пересчёт базовых порогов для конкретного объекта на основе накопленной экспертной разметки | Аналитик / желательно | Замер изменения F1-score модели до и после калибровки на отложенной выборке | Не реализовано |
| **NF-01:** соблюдать порог времени обработки — анализ выборки из 1000 аномалий не должен занимать более 5 минут | Производительность / обязательно | Замеры при заданной нагрузке на тестовом стенде | Не реализовано |
| **NF-02:** обеспечивать безопасность данных — все действия логируются, доступ только по временным учётным записям, данные не покидают периметр КИИ | Безопасность / обязательно | Аудит логов; проверка прав доступа; penetration-тест | Реализовано, проверено |
| **NF-03:** достигнуть точности ML-модели — F1-score ≥ 0.80 на валидационной выборке | Качество / обязательно | Кросс-валидация на исторических данных за 6 месяцев | В тестировании |
| **NF-04:** обеспечивать масштабируемость — решение должно работать на всех ~2000 объектах заказчика без деградации производительности | Масштабируемость / желательно | Стресс-тест на увеличивающейся выборке (100 → 1000 → 10000 объектов) | Не реализовано |
| **NF-05:** обеспечивать надёжность — система должна корректно обрабатывать пропуски в данных (сбои датчиков, рассинхрон по времени) без критических ошибок | Надёжность / обязательно | Инъекция пропусков в тестовые данные; проверка graceful degradation | Не реализовано |

---

## Легенда статусов

| Статус | Значение |
|---|---|
| **Реализовано, проверено** | Функция разработана и успешно прошла тестирование |
| **Реализовано, не проверено** | Функция разработана, но тестирование ещё не проведено |
| **В тестировании** | Функция находится на этапе активного тестирования |
| **Не реализовано** | Функция запланирована, но разработка ещё не начата |

## Приоритеты требований

| Приоритет | Описание | Примеры из реестра |
|---|---|---|
| **Обязательно** | Критичные требования, без которых решение теряет смысл или не может быть принято заказчиком | F-01, F-02, F-03, F-04, NF-01, NF-02, NF-03 |
| **Желательно** | Важные требования, улучшающие качество решения, но не блокирующие его запуск | F-05, F-06, F-07, NF-04, NF-05 |

**Примечание:** Формулировки сокращены для наглядности. В рабочем реестре — полные условия и ссылки на доказательства (протоколы тестирования, скриншоты, метрики).
