AS IS (Текущее состояние процесса)
Сбор данных:
На дорогах РФ установлено ~2000 метеостанций с радарами и видеокамерами
Радары фиксируют каждые 5 минут: скорость ТС, расстояние между машинами, длину автомобиля (классификация на 6 типов)
Данные усредняются в часовые показатели
Архив наблюдений накоплен за 5 лет
Анализ данных:
Работают автоматические алгоритмы выявления аномалий трафика
Система сравнивает фактические значения с ожидаемыми и подсвечивает отклонения (например, +654% по автопоездам)
Аномалии считаются за каждый полный час после получения свежих данных
Визуализация на карте: цветовые индикаторы статуса объектов (зелёный/жёлтый/красный/синий)
Принятие решений:
Данные используются для мониторинга состояния дорог и трафика
Среднесуточная интенсивность применяется для паспортизации дорог
Часовая и пятиминутная интенсивность — для оперативного анализа
Транспортные инженеры потенциально могут использовать данные для планирования ремонтов и строительства, но системной методики пока нет
Проблемы текущего состояния:
Алгоритмы обнаружения аномалий не валидированы экспертами
Архив данных не используется полностью для прогнозирования
Нет единой методики интерпретации результатов для дорожников
Отсутствует связь между данными трафика и погодными условиями в аналитике
