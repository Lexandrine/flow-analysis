Это исследовательский проект, направленный на валидацию промышленных алгоритмов детекции аномалий транспортных потоков. Используя 5-летний архив данных с дорожных метеостанций (радары, видеофиксация), мы проводим экспертный анализ расхождений между автоматическими предсказаниями системы и реальными событиями на дороге. Цель работы — повысить точность выявления инцидентов, предложить новые метрики оценки загруженности и создать методологическую базу для принятия решений транспортными инженерами при планировании ремонтов и строительстве дорог.
